# Partition & Kernel Images

This directory holds device partition dumps and recovery images used for dual-boot orchestration:
- `stock_boot_raw.img`: Android stock boot image (CloverOS / LineageOS Android 15), switched to when booting into Android.
- `fox.img`: OrangeFox Recovery image for Poco F1 (`beryllium`).

> [!NOTE]
> Large `.img` binaries are excluded from version control via `.gitignore`.
