# Legacy Prototypes & Scratch Files

This directory contains early HTML prototypes and standalone test bundles:
- `shell_prototype.html`: Early proof-of-concept prototype of the ButterOS mobile interface.
- `shell.html`: Pre-deployment snapshot (September 28, 2026).
- `exact_blackhole.bundle.js` & `three.min.js`: Experimental Three.js rendering dependencies.

> [!NOTE]
> The single canonical production shell is `debian-butteros/shell/shell.html`.
