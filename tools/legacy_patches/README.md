### Overview
These scripts (`apply_shell_fixes.py`, `patch_butteros_shell_v2.py`, `patch_shell.py`, `fix_syntax_and_cleanup.py`, `package_fox.py`) were one-off historical scripts created during early development. 

Running these legacy scripts will overwrite carefully audited, hardware-verified modifications in the live shell. They are preserved here strictly for historical reference and auditability.
